# mfd-scan (prototipo Node, fase 0)

Prototipo storico con cui MantoFreeDisk e' nato: report, ls aggregato e navigazione
su Node.js. **Congelato**: non si sviluppa piu', si conserva perche' la storia del
progetto fa parte del progetto.

- Il prodotto oggi e' `mfd-cli` in Rust (vedi `rust\`).
- `walker-node.mjs` e' il walker minimale usato da `bench\run-bench.ps1`: di lui
  ci importa ancora, vive del confronto fra implementazioni.
- I commenti nel codice citano documenti interni della fase 1 non inclusi nel repo
  pubblico: sono riferimenti storici, non link rotti.
