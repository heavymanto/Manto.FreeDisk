# Risultati dei benchmark

Qui vivono gli output degli script di `bench\` (run / startup / mem), un file per
sessione di misura: `AAAA-MM-GG-<macchina>-<target>.txt`.

Regola del progetto: **nessun numero in documentazione senza l'output completo da cui
proviene**. Ogni file va incollato per intero, comando eseguito compreso, cosi' chi
legge puo' verificare.

Le misure dipendono dalla macchina e dallo stato del disco: servono a confrontare le
implementazioni fra loro nella stessa sessione, non a classificare computer.
