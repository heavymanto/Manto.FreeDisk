# Security Policy

## Supported versions

The project is young: the latest release is the supported one.

| Version | Supported |
| ------- | --------- |
| 0.8.x   | ✅ |
| < 0.8   | ❌ |

## Reporting a vulnerability

Use GitHub's **private vulnerability reporting**: the *Report a
vulnerability* button on the Security tab reaches the maintainer without
public exposure, and you get an answer within a few days. Please do not
open a public issue for security matters.
